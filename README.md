# Busters — Gaming Studio Landing Page

A responsive game studio landing page built with React, Vite, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## SEO / Open Graph

Copy `.env.example` to `.env` and set your live domain:

```bash
VITE_SITE_URL=https://your-domain.com
```

This makes canonical URLs and OG image links absolute for social previews.
